# 豆包 · 跟着鼠标转头

一个纯静态首页：画面中央的人物会跟着鼠标左右转头。移动端换成触摸跟随。

在线地址见仓库 Pages 链接。

## 原理

人物转头的两段视频被抽成一帧帧静态图，按从最左到最右排好。页面只把鼠标横坐标映射成帧号，用 canvas 画对应那一帧，配一点缓动。没有 WebGL，也没有抠像——帧图边缘用 alpha 蒙版羽化，和页面背景色接上。

质感来自视频，代码只负责切帧。

## 素材来源

- 形象图 `hero.png`（未入库）由**豆包**生成，正面、纯色浅天蓝背景。
- 「看左」「看右」两段约 5 秒、1280×720、24fps 的图生视频，以同一张形象图作首帧。
- `frames/` 是从两段视频抽出的 123 帧，`f000` 最左、`f061` 正视、`f122` 最右，由
  `chengfeng-cursor-follow` 技能的 `build_frames.py` 生成（`--step 2 --width 1280`）。
- 帧图做过一次居中校正：以颈部中线为基准拟合平滑曲线平移每一帧，并补偿两段视频拼接处
  实测 14 像素的错位，消除鼠标经过中心时「抖一帧」的感觉。

## 本地打开

直接双击 `index.html` 即可，无需构建、无依赖。
